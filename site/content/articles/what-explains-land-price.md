乗り降りする人が多い駅ほど、周りの土地は高い。そう考えるのが自然だと思います。ところが、全国1,859駅で調べてみると、地価と乗降客数の結びつきは思ったほど強くありませんでした。もっと強く結びついていたのは、その街に住んでいる人の顔ぶれでした。

## 何を比べたか

- **地価**：駅から1.6km以内にある住宅地の地価公示（2026年）の中央値。商業地は含めていません。住む場所としての値段を見るためです
- **比べた指標**：乗降客数、駅から徒歩10分（800m）以内の店や施設の数（9種類）、駅がある市区町村の人口構成（4種類）、家賃の目安

地価と乗降客数の両方が分かる1,859駅を対象にしました。

関係の強さは「順位の相関」で測りました。地価の高い順と、指標の大きい順が、どのくらいそろっているかを表す数字で、1なら完全にそろい、0なら無関係、−1なら完全に逆です。東京都心の極端に高い地価に結果が引っぱられないよう、値そのものではなく順位を使っています。

高齢者の割合は −0.77 で、逆向きに強く結びついていました。

家賃の目安（住宅・土地統計調査の市区町村ごとの家賃から出した値）が0.91で最も高いのは、当然と言えます。地価と家賃は、どちらも「そこに住む値段」を別の面から測ったものだからです。これを除くと、上位に来るのは**若い人の割合（0.79）、一人暮らしの割合（0.78）、人口の増え方（0.72）**で、どれも「どんな人が住んでいるか」の指標です。

乗降客数は0.45で、コンビニの数（0.68）やスーパーの数（0.55）よりも弱い結びつきでした。

## なぜ乗降客数が効かないのか

乗降客数が多い駅には、2つの種類があります。ひとつは、周りに住む人が多い駅。もうひとつは、乗り換えや通勤で使われる駅です。

たとえば、郊外の大きな乗換駅や、空港の駅は、乗降客数が多くても周りは住宅地ではありません。成田空港駅は1日4万9千人が乗り降りしますが、周りの住宅地の地価は1平方メートルあたり3万2,400円でした。

同じくらいの乗降客数（1日3万〜5万人）の368駅で、地価の高い4分の1と低い4分の1を比べると、違いがよく分かります。

| | 地価が高い4分の1 | 地価が低い4分の1 |
|---|---:|---:|
| 地価（中央値） | 1㎡あたり89.9万円 | 1㎡あたり11.4万円 |
| 乗降客数（中央値） | 37,716人 | 35,942人 |
| コンビニ（徒歩10分以内） | 23軒 | 8軒 |
| 飲食店 | 84軒 | 32軒 |
| カフェ | 18軒 | 5軒 |
| スーパー | 7軒 | 3軒 |
| 病院・診療所 | 3軒 | 4軒 |
| 若い人（20〜39歳）の割合 | 29.8% | 20.2% |
| 一人暮らしの割合 | 57.3% | 33.8% |
| 関東の駅の割合 | 88% | 38% |

乗降客数はほぼ同じなのに、地価は8倍違います。地価の高い駅は、駅前の店が多く、若い人と一人暮らしが多く、ほとんどが関東にあります。病院・診療所だけは、地価の低い駅の方がわずかに多くなっていました。

地価が高い駅の上位には、竹橋、乃木坂、御成門、赤羽橋、国会議事堂前といった東京都心の駅が並びます。低い駅には、津（三重県）、熱海（静岡県）、小山（栃木県）、栗橋（埼玉県）、成田空港などがありました。

## 地価の上がり方も同じ傾向

2026年の地価公示で前年から何%上がったかについても、同じように調べました。

| 指標 | 地価の上がり方との順位の相関 |
|---|---:|
| 若い人の割合 | 0.72 |
| 人口の増え方 | 0.69 |
| 一人暮らしの割合 | 0.66 |
| コンビニの数 | 0.57 |
| 乗降客数 | 0.37 |
| 病院・診療所の数 | 0.17 |

地価が上がっている駅も、乗降客数より、若い人が多く人口が増えている街の駅でした。

## 病院の数は地価とほとんど関係がない

病院・診療所の数は、地価との相関が0.19で、調べた指標の中で最も弱い結びつきでした。

病院やクリニックは、住む人の数に応じて、どの街にもある程度そろっています。地価の高い街に集まるわけではありません。[人口の増減と駅前の店を比べた記事](/articles/population-change-and-station-shops/)でも、人口が減っている街と増えている街で、病院の数は変わりませんでした。

## この結果の読み方

- **相関は因果ではありません。** 若い人が多いから地価が高いのか、地価が高い街に住めるのが若い単身の会社員だからなのか、どちらの向きかは分かりません。おそらく両方が絡み合っています
- **住んでいる人の指標は市区町村の値です。** 同じ区の駅はすべて同じ値になるので、駅ごとの細かい違いは表していません
- **地価は住宅地だけです。** 駅前の商業地の地価は含めていないので、繁華街の土地の値段とは違います
- **店の数はOpenStreetMapの登録数です。** 登録の漏れがある地域では、実際より少なく出ています

## まとめ

- 駅の周りの住宅地の地価は、乗降客数（相関0.45）より、若い人の割合（0.79）や一人暮らしの割合（0.78）と強く結びついている
- 駅前の店では、コンビニの数（0.68）が最も強く結びついていた
- 同じくらいの乗降客数でも、地価は8倍違うことがある。違いは駅の規模ではなく、周りに住む人と店の数に出る
- 病院・診療所の数は、地価とほとんど関係がない（0.19）

住む駅を選ぶとき、「大きな駅だから便利で高い」とは限りません。乗り換えの駅と、人が住む街の駅は別物です。地価の割に住みやすい駅の探し方は、駅前スコアの記事[「地価が安いのに生活施設がそろっている駅はどこか」](https://eki.kakuni-lab.com/article/cheap-and-convenient)にまとめています。
