「Lサイズのロッカーならスーツケースが入る」と思っていませんか。私もそう思っていました。ところが、駅のコインロッカーの内寸を事業者ごとに並べてみると、同じ「L」でも高さが倍近く違いました。

この記事は、2026年9月まで公開していたコインロッカー検索のために集めたデータ（427駅・818か所）を使っています。

## 事業者ごとの内寸

データのうち、内寸（箱の内側の大きさ）が公開されていた事業者の数字です。表記は「幅×奥行×高さ」です。

| 事業者 | サイズ名 | 内寸（cm） | 料金（いちばん多い額） |
|---|---|---|---:|
| マルチエキューブ（JR東日本系） | SS | 34×65×15 | 800円 |
| | S | 34×65×33 | 1,000円 |
| | M | 34×65×50 | 1,100円 |
| | L | 34×65×**86** | 1,300円 |
| 東急線 | SLIM | 13.5×64×32.5 | 300円 |
| | S | 34.2×57.5×31.6 | 500円 |
| | L | 34.2×57.5×**50.2** | 600円 |
| | LW | 34.2×57.5×84.3 | 900円 |
| 横浜市営地下鉄 | S | 34.2×57.5×32 | 500円 |
| | M | 34.2×57.5×49.2 | 700円 |
| | L | 34.2×57.5×84 | 1,000円 |

**東急線のLは高さ50.2cmで、JR東日本系のM（50cm）とほぼ同じ大きさです。** JRのLに相当するのは、東急線ではLWという名前のサイズです。横浜市営地下鉄は、JRと同じようにLが80cm台ですが、奥行はJRより7.5cm浅くなっています。

つまり、「L」という名前だけでは、どのくらいの荷物が入るか分かりません。

さらに、東京メトロのロッカーはサイズの名前ではなく料金（300円・500円・600円・900円・1,000円）で区分されていて、内寸は公開されていませんでした。京王線、西武線、一部の私鉄のロッカーも、サイズ名と料金だけで内寸が分かりませんでした。

## 幅はどこもほぼ34cm

内寸が分かったロッカーでは、東急線の細長いSLIMを除き、幅はすべて34〜34.2cmでした。違うのは奥行（57.5cmか65cm）と高さです。

これは、荷物の厚みが34cmを超えると、どのサイズにも入らないということでもあります。スーツケースの厚み（床に置いたときの横幅の短い方）はたいてい30cm前後なので、多くは問題ありません。ただ、大きなボストンバッグやふくらんだリュックは、厚みが34cmを超えて入らないことがあります。

## 荷物ごとに必要なサイズ

代表的な荷物の外寸で、どのサイズに入るかを確かめました。荷物は立てても寝かせてもよいものとして、3辺を小さい順に並べて比べています。

| 荷物（外寸の目安） | JR東日本系 | 東急線 |
|---|---|---|
| リュック（30L程度・50×32×20cm） | S以上 | S以上 |
| 機内持ち込みのスーツケース（55×40×25cm） | **M以上** | L以上 |
| 預け入れMのスーツケース（67×47×28cm） | **L** | LW |
| 預け入れLのスーツケース（75×52×30cm） | **L** | LW |

注意したいのは、**機内持ち込みサイズのスーツケースが、JRのSサイズには入らない**ことです。Sは幅34cm・高さ33cmで、奥行だけが65cmあります。スーツケースを立てても寝かせても、幅40cmの辺を収める場所がありません。

また、預け入れ用のスーツケース（60〜70L以上）は、JRではLにしか入りません。Mは奥行が65cmで、高さ67cm前後のスーツケースは入らないからです。東急線では、Lでは足りず、LWが必要です。

## 台数で見ると、大きいロッカーは3割

JR東日本系のロッカーについて、サイズごとの台数を数えました。

```bars
マルチエキューブのサイズ別の台数（697か所、合計11万2,710台）
SS（高さ15cm） | 11030 | 11,030台
S（高さ33cm） | 41500 | 41,500台
M（高さ50cm） | 25955 | 25,955台
L（高さ86cm） | 33350 | 33,350台
LW | 875 | 875台
```

いちばん多いのはSで、スーツケースの入るLは全体の29.6%です。台数は、事業者が公開しているデータの値をそのまま足したものです。1か所で数百台を超える値もあり、実際の扉の数と一致するかは確かめられていません。台数そのものより、サイズや場所ごとの比率として読んでください。大きな荷物を持った旅行者が多い駅では、Lから先に埋まっていくことになります。

## 料金はサイズでどう上がるか

JR東日本系では、いちばん多い料金がS 1,000円、M 1,100円、L 1,300円でした。SからLに上げても300円しか変わりません。**迷ったら大きい方を選ぶのが安全です。** 入らなかったときに取り出して別の空きを探す手間の方が、300円よりずっと大きいからです。

東急線では、S 500円、L 600円、LW 900円でした。JRより安いぶん、奥行が浅く、スーツケースにはLWが必要です。

## 選ぶときのコツ

1. **サイズの名前ではなく内寸を見る。** ロッカーの扉や案内板には、たいてい内寸が書かれています
2. **荷物の3辺を測っておく。** スーツケースの外寸は、キャスターと取っ手を含めた大きさです。メーカーの表示には、キャスターを含まない数字もあります
3. **厚み34cmを超える荷物は、どのサイズにも入らない前提で考える。** 手荷物預かり所や、荷物預かりサービスを探す方が早いです
4. **機内持ち込みサイズでも、JRならMが要る。** Sに入るのはリュックや小さなバッグまで

## データについて

- 数字は2026年9月17日時点の各社の公開情報です。ロッカーは入れ替わることがあるので、実際の大きさは現地の表示で確かめてください
- 集めたデータの85%（697か所）はJR東日本系のマルチエキューブです。首都圏とJR東日本の駅に偏っていて、全国のロッカーの平均を表すものではありません
- 台数はマルチエキューブが公開しているデータの値です。実際の扉の数と一致するかは確かめていません
- 同じ事業者でも、古いロッカーは大きさが違うことがあります。今回のデータでは、JR東日本系の同じサイズ名の内寸はすべて同じでした
